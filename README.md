# Devs Note
1. Exit Folder 
```bash 
cd ..
```
2. Open in vs code on existing window
```bash 
code . -r
```
3. Git add current changes
```bash 
git add .
```
4. Git commit about there changes 
```bash
git commit -m "Your Comment"
```
5. Git changes push to github
```bash 
git push origin <branch> 
```
6. Git Current Branch name
```bash
git branch
```
7. Git current origin 
```bash
git fetch -v
```
8. Fetch Changes 
```bash 
git pull 
```+
